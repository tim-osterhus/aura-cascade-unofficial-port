# Aura Cascade 0.2.0 Beta

Restoration beta for Minecraft 1.21.1 on Fabric.

## Requirements

Minecraft 1.21.1, Fabric Loader 0.19.1 or newer, Java 21, Fabric API and Patchouli
1.21.1-93-FABRIC. The required Energy API is bundled. Back up existing worlds
before upgrading; this beta changes recipes and several gameplay systems.

## Highlights

- Replaces the clipped written-book guide with a navigable Encyclopedia Aura,
  including linked topics, crafting recipes, machine instructions and quests.
- Restores node inspection, visible aura transfer, consumer feedback and
  per-pedestal vortex power accounting.
- Adds the Bookshelf Coordinator's searchable contents browser and selected
  retrieval, with server-owned equipment slots and restored fairy behaviors.
- Restores wool-based Arcane Ingots, advanced wool processing, End Stone
  fortification and Arcane Ingot inputs for the Kaleidoscopic Enchanter.
- Restores waiting-item protection around consumers and corrects numerous
  enchantment, accessory, storage, ritual and utility behaviors.
- Fixes composed fairy/enchantment mining bonuses, bookshelf visibility,
  ordinary explosion block damage, and the Portable Red Hole's recurring blasts.
- White Aura Crystals are crafted from one Amethyst Shard surrounded by eight
  Gold Nuggets, yielding two crystals.

## Upgrade Notes

Equip accessories in their actual equipment slots; merely carrying them is not
equivalent to wearing them. Consult the Encyclopedia for current machine setup
and recipes. The Prismatic Wand copies a live source region and consumes
survival building materials; it does not duplicate container contents.

This is an unofficial port. Original Aura Cascade is by pixlepix, with the
1.8.x port credited to williewillus. Original texture credits and the MIT
copyright notice are retained in the distribution.

## Beta Scope

Validation includes supplied-material progression fixtures, UI/font checks,
negative controls, save/reload, and representative multiplayer behavior. It is
not an exhaustive survival playthrough of every combination or a large-server
soak test. External energy-receiver interoperability and third-party modpack
interactions remain areas for beta feedback. The full Red Hole lifetime was not
waited out in real time.

The final artifact hash, measured memory and exact release-check results are
recorded in the repository's release validation and publication records.
