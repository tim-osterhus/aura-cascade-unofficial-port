# Aura Cascade Reimagined 0.2.1 Beta

Visual-feedback hotfix for Minecraft 1.21.1 / Fabric. Requires Java 21,
Fabric Loader 0.19.1+, Fabric API and Patchouli 1.21.1-93-FABRIC.
Energy API is bundled. Back up existing worlds before upgrading.

## Changes

- Adds visible feedback for dropped-item crafting, including Angel's Steel.
- Briefly previews connections when an empty Aura Node is placed, without
  requiring or consuming Aura Crystals.
- Rechecks connection geometry when transferring aura, so newly placed nodes
  and intervening obstructions take effect without waiting for a cached scan.
- Opens the Aura creative tab on the first creative-inventory opening in a
  client session. Later openings preserve the player's selected tab.
- Stabilizes the Aura inspection HUD during transfers and nearby entity
  targeting; observed color rows display actual zero values instead of vanishing.
- Gives Encyclopedia opening links separate rows for clear navigation.
- Updates the display name and project link to Aura Cascade Reimagined while
  retaining existing registry IDs and world compatibility.
