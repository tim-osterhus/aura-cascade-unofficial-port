# Aura Cascade Reimagined 0.2.1 Beta

Minecraft 1.21.11 on Fabric. Requires Fabric Loader
0.19.5 or newer, Java 21, Fabric API, and Patchouli: Fabric Edition
1.21.11-94.4-FABRIC. Fabric API and Patchouli are external required
dependencies; Team Reborn Energy API 4.2.0 is bundled. Back up existing worlds
before trying this beta.
Use a new world or a backed-up trial; compatibility with old 0.1.x worlds is
not established. Do not downgrade a world opened by Minecraft 1.21.11.

## Changes

- Carries forward five 0.2.1 hotfixes: dropped-item crafting particles,
  including Angel's Steel combinations and machine outputs; aura-network placement
  previews and fresh connection-geometry checks; first-open Aura creative-tab
  selection while preserving later tab choices; inspection HUD rows remaining
  visible at actual zero during transfers, with nearby entities no longer hiding
  block inspection; and nine separate Encyclopedia landing links.
- White Aura Crystals use one Amethyst Shard surrounded by eight Gold Nuggets,
  yielding two crystals.
- Adapts registrations, saved data, recipes, item/entity rendering and Minecraft
  hooks to 1.21.11. HUD and storage-screen text use the target's explicit alpha
  colors; invisible Fairy Torch particles have a defined texture fallback.

## Validation And Limits

- 258 tests across 65 suites and 11 publishing-utility tests passed.
- All 15 multiplayer checks and three transformed-item lifetime checks passed.
- Creative-inventory checks and 18 Patchouli landing-link assertions passed.
- Packaged-client captures show node preview particles, Angelsteel crafting
  bursts, retained positive/zero Aura rows, colored sword icons, a displayed
  pedestal item and an animated fairy. The book passes actual-font layout checks
  for 41 entries and 371 pages.
- Dedicated-server probes cover changed gameplay hooks, native saved-data codecs,
  node/storage-book disk restart, a fueled White Ingot cycle, a complete White
  Gem Vortex craft, component-aware storage retrieval/conservation with rejection
  controls, and an actual third-party external-energy receiver.
- Fixtures supply raw materials and controlled starting states. These are bounded
  checks, not an exhaustive Survival playthrough or modpack compatibility claim.
  All fairy-role combinations, natural Scarer spawn rates, the full target Prism
  cycle and long-duration Red Hole expiry are not established.
- Known inherited issue: the Breeder Fairy may select juvenile animals. This was
  reproduced in the canonical 1.21.1 audit; this forward port does not fix it.
