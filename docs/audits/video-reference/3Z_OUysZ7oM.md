## Evidence conflicts and limits

- The focused video frames support ore preservation while common stone breaks, whereas the modern port README says common stone is protected. The radius remains presenter-only. This is an explicit version-sensitive contradiction, not proof of a current implementation defect. The 2015 videos and shipped 1.8.9 jar may differ.
- The custom guide and Baubles UI are visible legacy affordances. The modern port README documents intentional written-book and inventory-backed substitutions; this note records the source experience, not an instruction to change that decision.
- Captions were read across the whole video. Sampled stills are **not continuous viewing**. Mirror cues cover through 18:30; the remaining ~38 seconds are caption-supported outro. Tiny fairies, HUD deltas, chance effects and transient explosions cannot be quantified from selected stills.
- No production code, Java client, Gradle or game testing was performed.
