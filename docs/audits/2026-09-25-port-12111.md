# Fabric 1.21.11 Forward Port

Status: implementation in progress; not a release approval.

## Baseline

Canonical 1.21.1 source checkpoint: `44cc057`, pushed to `main`.
Target branch: `fabric/1.21.11`, created from that checkpoint.
The canonical measured `test build` passed 252 tests across 62 suites before
branching. Peak working set was 1334.4 MiB; peak private allocation 1448.9 MiB.
Ten publisher unit tests also passed. These are baseline results, not target
validation. The exact published 1.21.1 JAR was preserved privately with SHA-256
`2290a1a344fa8e1e43d631729b5f88d422923d573db90d1a592945fecc1aacc8`.

## Target Dependencies

- Minecraft 1.21.11, Java 21, Fabric Loader 0.19.5.
- Fabric API 0.141.6+1.21.11 and included Energy API 4.2.0.
- Patchouli: Fabric Edition, CurseForge project 1664943, file 8713841,
  `Patchouli-1.21.11-94.4-FABRIC.jar`, external required dependency.
  CurseForge and CurseMaven downloads matched at 879121 bytes, SHA-256
  `08f8834ea942a5eefcb49811dd753f5f169fe76d142858f71914245f3b2d4462`.
  Mod ID remains `patchouli`; CurseForge dependency slug is
  `patchouli-fabric-edition`. Do not confuse the two identifiers.
- Dependency resolution required Loom 1.17.14, which requires Gradle 9.5.0.
  Both run on Java 21. The earlier Loom 1.14.10 / Gradle 9.4.1 candidates failed
  dependency configuration and were replaced together.

Patchouli's binary metadata allows Minecraft >=1.21.11 <1.21.12. Its source
license is CC BY-NC-SA 3.0, not Aura's MIT license. It is not bundled into Aura.
The inspected source commit is `a96b648072f7dfad98acbb7c8379d7783741ac20`;
the binary does not attest to that build commit. Artifact resolution and the
target actual-font audit passed; interactive navigation is a separate gate.

## Validation Discipline

The first fully configured target compile reached the source and reported API
errors. It was not a successful build. Its peak working set was 1619.5 MiB and
private allocation 1656.2 MiB. The subsequent compile is an integration diagnostic,
not a release artifact. Existing baseline gameplay evidence is not relabeled.

The user removed cross-thread game-session coordination on 2026-09-25 because
the machine now has ample headroom. Aura's own measured workload remains bounded
under the previously requested 4.5 GB budget; samples are not an OS hard cap.

No target CurseForge upload has been made. Publication is authorized only after
target acceptance passes. Existing untested-mechanic gaps remain explicit.
